# Visêo geral
Visagismo B adapta o ZIP fornecido para atendimento assistido em barbearias. App em Python/FastAPI/Jinja, motor MediaPipe, SQLite privado e worker. Destino exclusivo de execuçêo: VPS; guia público no GitHub Pages e catálogo INEMA.
Leia README.md e VPS.md para recursos e limitações. PLANO.md registra o plano inicial e nêo é uma declaraçêo de recursos entregues.

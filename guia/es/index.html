Qué es

El conocimiento del barbero, organizado como servicio.

Un sistema de atención asistida, con la identidad de la barbería y recomendaciones revisadas antes de la entrega.

✂️ Análisis facial real

MediaPipe calcula proporciones a partir de una foto frontal. Las medidas aproximadas ayudan a conversar sobre opciones de estilo.

✂️ Decisión profesional

El barbero considera la preferencia, registra los ajustes, aprueba el informe y acuerda el retorno.

✂️ Operación en la VPS

Aplicación, worker, datos persistentes y HTTPS en Docker Compose. La consulta funciona incluso sin generar imágenes.

Cómo funciona

Desde la primera conversación hasta la siguiente atención.

El cliente comienza en la página pública de la barbería y envía la foto después del pago. El profesional también puede iniciar la atención desde el panel.

Página + pago→Preferencias + foto→Análisis→Revisión→Informe→Seguimiento
Requisitos previos

Una VPS, un dominio y tu barbería.

Punto de partida sugerido: Linux, 2 vCPUs, 4 GB RAM, 20 GB SSD. Ajusta según la carga. Sin GPU cuando uses un proveedor externo de imágenes.

Docker y Compose

Dominio apuntando a la VPS, puertos 80 y 443 disponibles y Docker Compose v2 instalado.

# comando
docker --version
docker compose version
Guía de uso · paso a paso

Instala en la VPS y realiza tu primera consulta.

Los comandos de abajo se ejecutan en la VPS. No hay una contraseña predeterminada; tú creas el acceso del profesional.

1

Descarga el proyecto

Clona el repositorio en la VPS.

git clone https://github.com/inematds/visagismo-b.git
cd visagismo-b
2

Configura tu dominio

Completa DOMAIN y PUBLIC_URL con el mismo dominio. El DNS debe apuntar a la VPS. Las claves opcionales se guardan solo en el entorno protegido.

cp .env.example .env
chmod 600 .env
nano .env
3

Sube la aplicación y el worker

Caddy se encarga del HTTPS. Si ya hay un proxy en la VPS, sigue la adaptación descrita en VPS.md.

docker compose config --quiet
docker compose up -d --build
4

Crea el acceso profesional

La contraseña se solicita sin mostrarse en la terminal. Cambia los datos de ejemplo por los tuyos.

docker compose exec app python -m app.manage create-user \
  --email voce@barbearia.com.br \
  --barbearia "Sua Barbearia" --profissional "Seu nome"
5

Atiende, revisa y entrega

Abre tu dominio e inicia sesión en el panel. En Configuración, copia la página pública para tus clientes. Registra la orientación final antes de habilitar el informe. Para dar seguimiento a los servicios:

docker compose ps
docker compose logs --tail=50 worker
6

Protege los datos

Haz copias de seguridad en un directorio privado y prueba la restauración según VPS.md. Las fotos vencen en 24 horas y los informes, en 90 días de forma predeterminada.

bash scripts/backup.sh /diretorio-protegido/visagismo-backups
Ejemplos

Cómo se integra el servicio a la rutina.

Escenarios ilustrativos de uso, sin afirmar que haya ventas o un aumento de la facturación.

El cliente quiere cambiar de estilo

Conversen sobre la rutina, envía una foto frontal autorizada y usa las sugerencias como punto de partida. La revisión del barbero convierte el borrador en orientación.

El cliente quiere mantener el corte

Registra cómo terminar en casa y la fecha de seguimiento. Comparte el informe mediante un enlace revocable de 7 días, sin exponer la foto.

La simulación frontal con flux2-klein es opcional. Las imágenes rechazadas por el filtro geométrico no se muestran; pasar el filtro no garantiza que se preserve la identidad.
